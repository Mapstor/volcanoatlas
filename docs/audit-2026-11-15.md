# Site audit — volcanosatlas.com — 2026-11-15

Scope: every URL of the live site (commit `e8bca73`, production = `main`), the full `data/content` set and the
Smithsonian export in `volcanoes.json`. Search Console and Bing exports of the same day were used to set priorities;
their figures are kept out of this public repository.

How it was checked: all sitemap URLs plus every internal link target fetched from production (1,289 addresses), server
HTML parsed for canonical / robots / structured data / links, 150 profile files compared field by field with the
Smithsonian export, pages rendered in headless Chrome at 1440 px and 390 px.

## Findings (state of production before wave 1)

### P0 — breaks trust or rankings

| # | Finding | Size |
| --- | --- | --- |
| 1 | Canonical tag of every page pointed at the homepage (root metadata inherited by all pages); `og:url` and `og:title` too | 380 of 380 parsed pages |

| 4 | Made-up page content: "Monitoring & alert status" computed from the last eruption year; population / infrastructure / aviation risk from a hardcoded country list; "Global ranking"; eruption timelines with random years on database-only pages; Japan/Kuril blocks on every database-only page | 150 profiles + all fallback pages |
| 5 | Stock photos from the Unsplash API shown as galleries of the volcano, with unrelated subjects; five `via.placeholder.com` images | 150 profiles |

### P2 — polish

- Prose: median 11.1 machine-writing tells per 1,000 words in the content files (target: 2 or fewer); none of the 204
  files passes.
- Design: generic dark template, emoji as icons, gradient headlines, no real imagery.
- 45 of the 213 indexable pages have a title longer than 60 characters.
- No cookie consent mechanism while Google Analytics and Microsoft Clarity set cookies.

### What was sound

Elevation, type and coordinates match the Smithsonian export on 148 of 149 comparable profiles. `robots.txt` leaves all
crawlers open. Production runs the code in `main`.

## Fix waves

1. **Plumbing and falsehoods (done in this change).** Per-page canonicals and Open Graph; server-rendered structured
   data with nothing invented; every internal link resolved or removed; crashes gone; working maps; phone menu; honest
   database-only pages (noindex); made-up boxes, schema and stock photos removed; real counts everywhere; sitemap from
   real routes; 404 page; real icon files; trust pages that match the site.
2. **Volcano articles.** Fact-check each profile against the Smithsonian eruption record, run the prose pass, then
   render the article sections, timelines and comparison tables. Highest-traffic profiles first.
3. **Database-only pages.** Rebuild as real data pages or keep them out of the index; settle the Smithsonian
   permission question before ads.
4. **Trust frame.** Named author with real credentials, Person markup, methodology and sources page, final
   "how this site is made" text.
5. **Hubs.** `/countries` as a data page with one counting rule; fact-check the topic and ranking pages against
   primary sources (NOAA NCEI, USGS); titles; world map with all records.
6. **Design.** Three looks on a real page, owner picks, then build; licensed imagery; final map tiles.
7. **Close.** Remaining prose pass, Raptive readiness pass, logged human review of the top pages, freeze.
